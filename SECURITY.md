# Security

assay's job is to catch supply-chain attacks in other people's releases, so a flaw in assay itself (a way to make it report "clean" for a bad release, or to leak its tokens) matters more than most.

## Reporting a vulnerability

Report it privately through GitHub: **[Security > Report a vulnerability](https://github.com/epheterson/assay/security/advisories/new)**. Please do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, and what an attacker could reach with it. You will get an answer as soon as I can, and credit in the advisory unless you would rather not.

## Supported versions

The `master` branch, which is what the scheduled workflow runs. Fixes are not backported.
